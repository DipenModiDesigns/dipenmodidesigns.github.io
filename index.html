About me

From graphic design to frontend development.

I started in 2018 doing part-time web and graphic design at GlooCab, creating digital assets and supporting website presentation.

In 2020 I joined iFlair Web Technologies as a web designer, converting PSD and Adobe XD designs into responsive layouts and WordPress themes. That work pulled me into frontend development: I became a frontend developer in 2022 and a senior frontend developer in 2023, working with Vue.js, React.js, Tailwind CSS and SCSS.

From March 2024 to October 2026 I was a senior frontend developer at IZYGROW BV, building Craft CMS templates, SaaS dashboard components for Payit, interactive elements like configurators and SVG maps, and Laravel-based application frontends together with backend developers.
